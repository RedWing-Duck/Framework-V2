BREAKER QA — Week 01: THIS PLACE HAS A BIG FOOTPRINT
Build tested: big-footprint.html
Method: every command below was typed into the actual build
(headless, same engine code). Failures only.
"TOUR 1-16" = steps 1-16 of the Critical Path verified
walkthrough (ends on arrival at R11, ESCAPE begins).
Bugs already logged as CP-01 to CP-03 are not repeated here.

==============================================================
P1
==============================================================

ID: BR-01
Severity: P1 (a correct answer ends the game; chat will hit this
constantly)
Location: all "said" matching (verbs add-on) and command parsing
Steps to reproduce:
  TOUR 1-16, open giraffe gate, south, south, south, say giraffe!
Expected: Nando accepts the GIRAFFE alibi (GDD 7).
Actual:
  "You try that. The universe gives you a look usually reserved
  for bad checks."
  CAUGHT ... GAME OVER.
Root cause: punctuation isn't stripped from typed input, so
"giraffe!" never matches "giraffe". The same cause produces:
  - Q1 (R5): say both.  /  say "both"  -> counted wrong, +1 strike
  - P3 (R2, ESCAPE): push 13th step.  -> "It's just a step." and
    a clock turn lost
  - P1 (R4, ESCAPE): play cielito lindo.  -> wrong-song text and
    a clock turn lost
  - Movement: north.  -> "I don't understand"
(Q2 only survives because "dog eared" alone also matches.)
Suggested fix: in parse(), replace everything except letters,
digits, spaces, hyphens and apostrophes with spaces before
splitting. One change fixes all five symptoms.
